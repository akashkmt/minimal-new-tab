## Features

**Core**
- Clock with 12h/24h toggle
- Live weather via geolocation (wttr.in)
- Search bar - Google, DuckDuckGo, or Bing; press `/` to focus
- Quick links with keyboard shortcuts (keys `1`–`9`)
- Greeting with custom name
- Top widget: Day progress %, motivational quote, week number, or none
- Age meter: live age display at page bottom (opt-in via birthday)

**Panels** - draggable, resizable, toggle on/off
| Panel | Description |
|---|---|
| Today's Todos | Daily task list, resets each day |
| Focus Timer | Pomodoro-style work/break timer |
| World Clocks | Multiple timezones at a glance |
| Habits | Daily habit tracker |
| Scratch Pad | Freeform notes with Markdown preview |
| Countdown | Days-until counter for any event |

**Settings**
- Theme: Light / Dark / System
- Time format: 12h / 24h
- Search engine: Google / DuckDuckGo / Bing
- Custom work/break durations for Focus Timer
- Add/remove habits, world clock timezones, quick links
- Named countdown event with target date
- Birthday input for age meter (optional)

## Install

[Chrome Web Store](https://chromewebstore.google.com/detail/minimal-%3E-new-tab/gdmkfjlfphjkiglangkfgkgbahgdkjhl)

Or load unpacked: clone repo → `chrome://extensions` → Enable Developer mode → Load unpacked → select folder.
